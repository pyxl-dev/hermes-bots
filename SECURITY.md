# Sécurité

Une faille dans Hermes Bots se signale en privé, par le [signalement privé de GitHub](https://github.com/pyxl-dev/hermes-bots/security/advisories/new), jamais dans une issue publique.

Ce dépôt est une bêta sans support : le signalement est lu et corrigé au mieux, sans délai garanti.

Hors périmètre : les failles de [Hermes Agent](https://github.com/NousResearch/hermes-agent) lui-même, à signaler à son projet.
